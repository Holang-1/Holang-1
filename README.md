## 🚀 Featured Projects

### 📦 LogisticsConnect

A distributed logistics tracking system built around **REST services and asynchronous messaging**.

The project consists of multiple services that communicate to process logistics and transit information.

**Technologies & concepts:**

* Java
* Javalin
* REST APIs
* ActiveMQ
* JMS
* Message Topics
* Service-to-service communication
* ETA calculation
* Maven
* Docker
* Distributed systems

The system includes services for **hub management, delay stages, and transit/ETA processing**, with messaging used to communicate package status information between services.
